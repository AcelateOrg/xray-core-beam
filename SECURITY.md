# Security

If you find a vulnerability (traffic or DNS leaking past the tunnel, a kill
switch bypass, protocol or TLS flaws, code execution and so on),
**please don't open a public issue**.

Report it privately through GitHub: the **Security** tab → **Report a
vulnerability** in this repository. Include the Beam version, OS, steps to
reproduce and, if you can, the possible impact.

We'll reply once we've looked into it and agree with you on when the fix is
disclosed.

Only the latest released version is supported.
